# BlueVPN 0.4.9 — تغییر زنده لوکیشن

## رفتار جدید
وقتی کاربر متصل است:
1. صفحه لوکیشن‌ها را باز می‌کند.
2. لوکیشن جدید را انتخاب می‌کند.
3. صفحه اصلی نتیجه انتخاب را دریافت می‌کند.
4. اتصال فعلی به‌صورت کنترل‌شده متوقف می‌شود.
5. صف مسیرهای لوکیشن جدید ساخته می‌شود.
6. بهترین مسیر لوکیشن جدید اجرا و از داخل Xray بررسی می‌شود.
7. فقط پس از عبور واقعی اینترنت، وضعیت سبز می‌شود.

کاربر لازم نیست «قطع اتصال» بزند و دوباره دکمه «اتصال» را لمس کند.

## جزئیات
- انتخاب همان لوکیشن فعلی باعث Restart بی‌دلیل نمی‌شود.
- اگر کاربر قطع باشد، انتخاب لوکیشن فقط مقصد را تغییر می‌دهد و خودکار متصل نمی‌شود.
- اگر هنگام Failover لوکیشن دیگری انتخاب شود، صف قبلی کنار گذاشته و صف مقصد جدید اجرا می‌شود.
- تایمر اتصال جدید پس از تأیید واقعی از صفر شروع می‌شود.
- جایگزینی خودکار بین مسیرهای همان لوکیشن همچنان فعال است.
