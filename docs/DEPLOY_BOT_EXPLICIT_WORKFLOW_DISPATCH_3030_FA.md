# رفع نشدن Build جدید در ربات Deploy — BlueVPN 3.0.30

## علت
ربات نسخه قبلی پس از Push فقط منتظر رخداد خودکار `push` در GitHub Actions می‌ماند. بررسی مخزن نشان داد Commitهای جدید روی شاخه `main` ثبت شده‌اند، اما Run جدیدی بعد از Build شماره 74 ساخته نشده است. در نتیجه وضعیت ربات «بیکار» بود ولی آخرین Build همچنان قدیمی نمایش داده می‌شد.

## راه‌حل
پس از تأیید SHA شاخه، ربات اکنون endpoint رسمی زیر را صدا می‌زند:

```text
POST /repos/{owner}/{repo}/actions/workflows/{workflow}/dispatches
```

بدنه درخواست:

```json
{"ref":"main"}
```

Workflow از قبل دارای `workflow_dispatch` است. ربات همچنین وضعیت فعال بودن Workflow را بررسی و در صورت نیاز آن را فعال می‌کند.

## تغییرهای رفتاری
- دکمه «ساخت فوری» مستقیماً آخرین Commit شاخه را Build می‌کند.
- Commit خالی برای تحریک Push ساخته نمی‌شود.
- Runهایی که قبل از درخواست جدید وجود داشته‌اند انتخاب نمی‌شوند.
- وضعیت، SHA شاخه و SHA آخرین Build را جداگانه نمایش می‌دهد.
- اگر Token مجوز Actions write نداشته باشد، خطای روشن نمایش داده می‌شود.
