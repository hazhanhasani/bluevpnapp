# BlueVPN 3.0.37 — رابط مینیمال الهام‌گرفته از ساختار JumpJump

این نسخه ظاهر اندروید BlueVPN را بدون کپی مستقیم از برند یا دارایی‌های JumpJump بازطراحی می‌کند.

## صفحه اصلی

- صفحه اصلی در ابعاد معمول موبایل بدون اسکرول ساخته می‌شود.
- نام BlueVPN، وضعیت حساب و نسخه برنامه در بالای صفحه قرار دارد.
- کنترل اتصال از Orb بزرگ به یک کنترل کپسولی با دکمه متحرک تبدیل شده است.
- وضعیت اتصال، توضیح مرحله، پینگ، زمان، دانلود و آپلود به‌شکل فشرده نمایش داده می‌شوند.
- کارت انتخاب سرور در پایین صفحه ثابت و در دسترس است.
- حجم و زمان باقی‌مانده بدون بنر تبلیغاتی Premium نمایش داده می‌شوند.

## صفحه مکان‌ها

- ظاهر تمام‌مشکی با کارت‌ها و خطوط ظریف.
- تب‌های «مکان‌ها»، «مورد علاقه» و «اخیر».
- ردیف «پیش‌فرض» برای انتخاب خودکار بهترین مسیر.
- جست‌وجوی مکان، علاقه‌مندی، پینگ ذخیره‌شده و تعداد مسیرها.
- تاریخچه اتصال موجود برای ساخت تب «اخیر» استفاده می‌شود.

## حفظ قابلیت‌ها

منطق اتصال، تغییر زنده لوکیشن، BlueAI، ورود ایمیلی و پیامکی، اشتراک مرزبان و پاسارگارد و پنل سوم سراسری تغییری نکرده است.
