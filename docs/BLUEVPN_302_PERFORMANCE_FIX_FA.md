# BlueVPN 3.0.2 — Performance Fix

این نسخه مسیرهای سنگین رابط کاربری را از Thread اصلی اندروید خارج می‌کند.

- نمایش اولین فریم بدون انتظار برای اسکن همه کانفیگ‌ها
- کش ۱۲ ثانیه‌ای فهرست کانفیگ‌های Decode شده
- کش JSON امتیازهای شخصی و جمعی BlueAI
- انتخاب مسیر هوشمند در Dispatchers.IO
- کاهش تست اتصال از دو دور ۸ آدرس به یک دور ۳ آدرس کوتاه
- Timeout هر تست ۱.۵ ثانیه
- کاهش وقفه تعویض هسته و مسیر جایگزین
- صفحه سرورها از کش رندر می‌شود و در پس‌زمینه تازه‌سازی می‌گردد
- تشخیص اپراتور برای چند ثانیه Cache می‌شود تا UI بلاک نشود

تأیید نهایی APK توسط GitHub Actions انجام می‌شود.

- اولویت تشخیص اپراتور با MCC/MNC سیم‌کارت دیتای فعال است؛ نام قدیمی سیم‌کارت دوم باعث نمایش سامانتل نمی‌شود.
