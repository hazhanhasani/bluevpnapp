# BlueVPN 3.0.19 — کاهش داغ‌شدن و مصرف باتری

این نسخه فشار اضافه‌ای را که بعد از اتصال روی پردازنده، شبکه و GPU ایجاد می‌شد حذف می‌کند.

## علت اصلی داغ‌شدن

در نسخه قبلی چند بررسی هم‌زمان فعال بود: گزارشگر پس‌زمینه هر ۳۲ ثانیه، Heartbeat صفحه اصلی هر ۳۰ ثانیه، تست سلامت و Real Ping هر ۴۵ ثانیه. هر اثبات تونل نیز چهار اتصال شبکه را هم‌زمان باز می‌کرد. علاوه بر آن، Orb در حالت متصل به‌طور دائمی انیمیشن ۶۰ فریم اجرا می‌کرد.

## رفتار جدید

- فقط یک گزارشگر پس‌زمینه مسئول Heartbeat اتصال زنده است.
- فاصله گزارش بر اساس وضعیت گوشی ۷۵، ۹۰ یا ۱۲۰ ثانیه است.
- اثبات واقعی اینترنت از داخل Xray به‌صورت ترتیبی انجام می‌شود و با اولین پاسخ موفق متوقف می‌شود.
- اثبات معتبر اخیر برای مدت کوتاه استفاده مجدد می‌شود؛ وضعیت VPN اندروید در هر گزارش دوباره بررسی می‌شود.
- تست‌های تکراری صفحه اصلی و Real Ping دوره‌ای حذف شدند.
- آمار سرعت هر ۲ ثانیه به‌روزرسانی می‌شود.
- Orb فقط هنگام «در حال اتصال» پالس می‌زند و در حالت متصل ثابت است.
- بررسی Auto-heal به بازه ۳ دقیقه منتقل شد.

تشخیص اتصال زنده همچنان به روشن‌بودن هسته اکتفا نمی‌کند و به VPN Transport اندروید و اثبات واقعی عبور درخواست از Xray نیاز دارد. این نسخه نیاز به Migration دیتابیس ندارد.
