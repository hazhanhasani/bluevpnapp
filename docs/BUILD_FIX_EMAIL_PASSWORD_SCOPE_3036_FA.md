# BlueVPN 3.0.36 — رفع خطای Build ورود ایمیلی

## خطای رفع‌شده

کامپایل Kotlin در فایل `BlueVpnSubscriptionsActivity.kt` با خطای زیر متوقف می‌شد:

```text
Unresolved reference 'password'
```

علت این بود که متغیر `password` درون بلوک مقداردهی اولیه خودش استفاده شده بود. شنونده `setOnEditorActionListener` از بلوک `apply` خارج شد و بعد از تکمیل ساخت فیلد ثبت می‌شود.

## محافظت در برابر تکرار

- سورس خوانای `android-source` و سورس Base64 مولد باید دقیقاً یکسان باشند.
- اعتبارسنج مولد، ارجاع به `password.text` در خط مقداردهی اولیه را رد می‌کند.
- آزمون رگرسیون جداگانه برای فرم ورود ایمیلی اضافه شده است.

تمام قابلیت‌های نسخه 3.0.35، شامل ورود ایمیلی/پیامکی و پنل سوم سراسری، حفظ شده‌اند.
