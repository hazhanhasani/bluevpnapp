# BlueVPN 3.0.5 — Fast Connect & Central Version

این نسخه با الهام از رفتار ساده و سریع کلاینت‌هایی مانند V2Box و Npv Tunnel، مسیر اتصال را سبک‌تر می‌کند:

- رابط اصلی قبل از اسکن MMKV، آماده‌سازی Asset و درخواست‌های شبکه رسم می‌شود.
- فهرست ۸۰+ سرور در چند فراخوانی پشت‌سرهم دوباره Decode نمی‌شود.
- رتبه‌بندی سرورها مقدارهای SharedPreferences و BlueAI را فقط یک بار برای هر سرور محاسبه می‌کند.
- تست اینترنت با اولین Endpoint موفق تمام می‌شود و منتظر Endpointهای کند یا مسدود نمی‌ماند.
- زمان‌های ثابت تعویض Core و Failover کوتاه‌تر شده‌اند.
- صفحات سرورها، تنظیمات و اشتراک در ورود اول دو بار ساخته نمی‌شوند.
- بررسی بروزرسانی پس از رسم UI و فقط یک بار زمان‌بندی می‌شود.
- `release.json` منبع نسخه Backend است و Android از `branding/app.json` استفاده می‌کند؛ Workflow هر دو را همگام می‌کند.
