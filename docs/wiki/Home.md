# BlueVPN Wiki

Welcome to the BlueVPN technical Wiki.

BlueVPN is a synchronized multi-platform VPN project consisting of Android, Windows and iOS clients, a WordPress control plane, site/theme integration and managed gateway tooling.

## Start here

- [[Architecture]] — how the components fit together
- [[Releases]] — versioning, Project Health and publication
- [[Troubleshooting]] — common CI and runtime problems

## Repository documentation

The version-controlled canonical documentation is kept under the repository's `docs/` directory. Wiki pages are intentionally mirrored from `docs/wiki/` so changes can be reviewed with the source code.

## Current version

Always read `version.json` from the default branch for the current synchronized project version. Avoid hard-coding a version number into this Wiki page because releases are automated.
