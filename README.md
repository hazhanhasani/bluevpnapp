# BlueVPN 3.0.20 — حذف قطعی فاکتورهای باطل BluePay

این نسخه مشکل بازشدن دوباره صفحه پرداخت منقضی را رفع می‌کند.

## رفتار جدید فاکتور

- اگر صفحه پرداخت باز بماند، فاکتور حداکثر ۳۰ دقیقه اعتبار دارد.
- بعد از بازگشت کاربر از صفحه پرداخت، مهلت باقی‌مانده به ۵ دقیقه محدود می‌شود.
- پس از پایان مهلت، رکورد فاکتور باطل از جدول `orders` حذف می‌شود؛ دیگر با وضعیت‌های `abandoned`، `expired_local` یا `superseded` نگهداری نمی‌شود.
- پیش از استفاده مجدد از هر لینک ذخیره‌شده، وضعیت واقعی آن با API بلوپی بررسی می‌شود.
- اگر BluePay همان `payment_id` یا همان لینک فاکتور باطل را دوباره برگرداند، Backend آن را رد می‌کند و لینک منقضی به اپلیکیشن نمی‌دهد.
- ساخت فاکتور تازه با شناسه سفارش جدید تا دو بار تکرار می‌شود.
- حذف یا لغو فاکتور نامعتبر در BluePay نیز به‌صورت Best-effort با `DELETE` و سپس مسیر `cancel` انجام می‌شود.
- اپلیکیشن در پاسخ `404/410` شناسه فاکتور قبلی را از حافظه پاک می‌کند.

نیازی به Migration دیتابیس نیست و Schema همچنان نسخه 11 است.
