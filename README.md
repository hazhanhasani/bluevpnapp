# BlueVPN 3.0.1 Ultimate AI

نسخه اندروید و پنل مدیریت BlueVPN با هسته هوشمند مسیر.

## قابلیت‌های واقعی این بسته

- PasarGuard و Marzban خودکار، GuardCore دستی از طریق ربات
- یادگیری شخصی از مدت اتصال، موفقیت و شکست هر مسیر
- یادگیری جمعی ناشناس بر اساس اپراتور، Wi-Fi/موبایل، ساعت و حالت اتصال
- امتیاز BlueAI برای مرتب‌سازی سرورها
- ترمیم خودکار پس از دو افت کیفیت متوالی
- داشبورد BlueAI داخل اندروید
- مرکز فرمان هوشمند در پنل مدیریت
- بازخورد و گزارش فنی کاربر
- کنترل روشن/خاموش جمع‌آوری شاخص‌های فنی
- عدم جمع‌آوری محتوای ترافیک یا مقصدها
- نسخه‌گذاری خودکار 3.0.0، 3.0.1 و ...

## نکته انتشار

ساختار و Syntax بررسی شده‌اند. کامپایل APK نهایی در GitHub Actions انجام می‌شود.
