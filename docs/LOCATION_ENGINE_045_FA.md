# موتور لوکیشن BlueVPN 0.4.5

## اصلاح تشخیص لوکیشن
- تشخیص کشور ابتدا با پرچم انجام می‌شود.
- سپس عبارت کامل نام کشور یا شهر بررسی می‌شود.
- کدهای دو یا سه حرفی فقط به‌صورت کلمه مستقل پذیرفته می‌شوند.
- آدرس سرور دیگر برای حدس کشور استفاده نمی‌شود؛ نام دامنه‌های CDN باعث خطا می‌شد.
- کانفیگ‌های ناشناخته همگی در «سایر» جمع نمی‌شوند و براساس نام خودشان گروه مستقل می‌گیرند.
- انتخاب یک لوکیشن هرگز به لوکیشن دیگری Fallback نمی‌کند.

## افزایش سرعت
- تست سنگین همه کانفیگ‌ها از صفحه لوکیشن حذف شد.
- فهرست فقط از نتایج ذخیره‌شده استفاده می‌کند.
- هنگام اتصال، دو تست اینترنت به‌صورت موازی اجرا می‌شوند.
- حداکثر انتظار هر مسیر حدود ۵.۵ ثانیه است.
- مسیر خراب سریع رد می‌شود و مسیر بعدی همان لوکیشن امتحان می‌شود.
- مسیر ناموفق برای ۱۰ دقیقه در اولویت پایین می‌ماند.
