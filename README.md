# BlueVPN 3.0.23 — اصلاح تاریخ اعتبار اشتراک

این نسخه مشکل تبدیل اشتراک یک‌ماهه به اعتبار همان روز را برطرف می‌کند.

- تاریخ نهایی از آخرین سفارش فعال‌شده و مدت واقعی پلن بازسازی می‌شود.
- PasarGuard بعد از هر ساخت یا تمدید دوباره خوانده می‌شود و تاریخ ثبت‌شده تأیید می‌گردد.
- برای نسخه‌های مختلف PasarGuard قالب Unix seconds، ISO-8601 و milliseconds پشتیبانی می‌شود.
- پاسخ قدیمی یا کوتاه‌تر پنل دیگر تاریخ معتبر پرداخت‌شده را کاهش نمی‌دهد.
- حساب‌های آسیب‌دیده هنگام Startup شناسایی و تاریخ پنلشان در پس‌زمینه اصلاح می‌شود.
- تاریخ‌های نمایشی همچنان شمسی و Asia/Tehran هستند و محاسبات داخلی UTC باقی می‌مانند.
