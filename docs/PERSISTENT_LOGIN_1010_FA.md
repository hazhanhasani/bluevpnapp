# حفظ ورود کاربر — BlueVPN 1.0.10

- Android: 1.0.10
- Version Code: 24
- Build ID: 20260804103242

## علت خروج قبلی

کد قبلی برای هر پاسخ HTTP 401 تابع `logout()` را اجرا می‌کرد و توکن ورود را
حذف می‌کرد. یک پاسخ موقت در زمان Deploy یا همگام‌سازی برای خروج کامل کافی بود.

## رفتار جدید

- پاسخ موقت 401 دیگر اطلاعات ورود را پاک نمی‌کند.
- توکن ورود در دو SharedPreferences مستقل ذخیره می‌شود.
- در صورت خالی‌شدن محل اصلی، اطلاعات از نسخه پشتیبان بازیابی می‌شوند.
- برای هر دستگاه Refresh Token جداگانه با اعتبار بلندمدت ساخته می‌شود.
- اگر Access Token منقضی یا نامعتبر شود، برنامه بدون نمایش صفحه ورود آن را
  خودکار تمدید و درخواست را تکرار می‌کند.
- نشست فعال با هر درخواست موفق دوباره ۱۲۰ روز تمدید می‌شود.
- فقط خروج صریح کاربر، غیرفعال‌کردن دستگاه توسط مدیر یا غیرفعال‌شدن حساب،
  اطلاعات ورود را باطل می‌کند.
- Reset Devices در پنل مدیریت Refresh Token دستگاه‌ها را نیز باطل می‌کند.
- ستون‌های جدید دیتابیس توسط Database Autopilot خودکار ساخته می‌شوند.

## نکته نسخه اول پس از نصب

کاربری که قبلاً به‌خاطر باگ خارج شده است یک‌بار در نسخه 1.0.10 وارد می‌شود تا
Refresh Token جدید دریافت کند. از بروزرسانی‌های بعدی دیگر نباید ورود تکرار شود.
