# BlueVPN 0.4.7 — تأیید اتصال واقعی

## ایراد قبلی
روشن‌شدن سرویس Xray به‌عنوان اتصال موفق نمایش داده می‌شد. درخواست HTTP
تست نیز بدون اجبار به پروکسی داخلی اجرا می‌شد و ممکن بود از اینترنت مستقیم
گوشی پاسخ بگیرد. در نتیجه صفحه سبز می‌شد، در حالی که کانفیگ کار نمی‌کرد.

## اصلاح
- حالت اجرای برنامه قبل از اتصال روی VPN قرار می‌گیرد.
- Local Proxy هسته Xray فعال می‌شود.
- درخواست سلامت فقط از `127.0.0.1` و پورت HTTP داخلی Xray ارسال می‌شود.
- اگر درخواست از داخل هسته عبور نکند، صفحه سبز نمی‌شود.
- مسیر خراب رد می‌شود و مسیر بعدی همان لوکیشن آزمایش می‌شود.
- سرویس روشن ولی بدون اینترنت متوقف می‌شود.
- زمان اتصال فقط بعد از تأیید واقعی آغاز می‌شود.
- اتصال جدید همیشه تایمر را از صفر شروع می‌کند.
