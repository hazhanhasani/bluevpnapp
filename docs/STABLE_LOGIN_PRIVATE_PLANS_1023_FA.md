# BlueVPN 1.0.23

## رفع خروج بی‌دلیل

علت اصلی، اجرای هم‌زمان چند درخواست تمدید ورود بود. اولین درخواست Refresh
Token را عوض می‌کرد و درخواست دوم با توکن قبلی، نشست را نامعتبر تشخیص می‌داد.

اصلاح‌ها:

- در Android فقط یک Refresh هم‌زمان اجرا می‌شود.
- درخواست‌های منتظر، توکن تازه‌شده را دوباره استفاده می‌کنند.
- خطای اینترنت، Timeout یا خطای موقت سرور اطلاعات ورود را پاک نمی‌کند.
- Backend توکن قبلی را تا ۱۰ دقیقه برای Raceهای هم‌زمان معتبر نگه می‌دارد.
- ستون‌های لازم خودکار به PostgreSQL اضافه می‌شوند.
- خروج واقعی فقط با دکمه خروج، غیرفعال‌شدن حساب/دستگاه یا رد قطعی Refresh است.

## مخفی‌بودن پلن‌ها

- `/api/v1/plans` اکنون ورود معتبر می‌خواهد.
- برنامه درخواست پلن را با Access Token می‌فرستد.
- قبل از ورود هیچ درخواست پلن اجرا نمی‌شود.
- اگر نشست در زمان دریافت پلن نامعتبر شود، کارت‌ها حذف و صفحه ورود نشان داده می‌شود.
