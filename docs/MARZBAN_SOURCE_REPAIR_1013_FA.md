# BlueVPN 1.0.13 — تعمیر منبع Marzban

- Android: 1.0.13
- Version Code: 27
- Build ID: 20260804112614

## علت نمایش‌ندادن کانفیگ‌های Marzban

1. نسخه قبلی فقط `subscription_url` را می‌خواند. اگر لینک مرزبان خالی،
   نسبی یا بدون XRAY_SUBSCRIPTION_URL_PREFIX بود، منبع Marzban حذف می‌شد.
2. پلن‌های قدیمی امکان ویرایش پنل دوم نداشتند.
3. کاربران قبلی پس از اتصال Marzban به پلن، خودکار در Marzban ساخته نمی‌شدند.
4. پاسخ POST/PUT بعضی نسخه‌های Marzban همه فیلدهای محاسبه‌شده را برنمی‌گرداند.

## اصلاح

- فیلد `links` پاسخ API Marzban مستقیماً خوانده می‌شود.
- وابستگی اصلی به subscription URL مرزبان حذف شد.
- لینک نسبی به Base URL پنل متصل و کامل می‌شود.
- پس از ساخت/ویرایش کاربر، GET مجدد اجرا می‌شود.
- پنل دوم پلن‌های قدیمی قابل ویرایش است.
- دکمه انتقال همه کاربران فعلی پلن اضافه شد.
- Sync یک‌دقیقه‌ای اپ نیز کاربر مفقود Marzban را خودکار ایجاد می‌کند.
- لینک نهایی همچنان یک لینک BlueVPN و ترکیبی است.
