# اصلاح جداسازی سرورهای رایگان و Premium — نسخه 3.0.75

## مشکل

در حالت انتخاب خودکار، مسیر سریع پس از بررسی سرورهای متعلق به پلن فعال، فهرست سراسری MMKV را نیز پیمایش می‌کرد. این فهرست می‌تواند هم‌زمان شامل سرورهای رایگان، اشتراک Premium قبلی، اشتراک فعلی و پروفایل‌های قدیمی باشد. همچنین Cache نامزدها فقط زمان‌محور بود و به وضعیت پلن وابسته نبود.

صفحه مکان‌ها نیز هنگام دریافت چند Broadcast پی‌درپی از Importer می‌توانست چند بار پشت سر هم Reload شود و اگر Decode یا Import خطا می‌داد، متغیر Loading پاک نشود.

## اصلاح

- Pool سرورها فقط از GUIDهای اشتراک فعال ساخته می‌شود.
- در Premium فقط Subscription با URL دقیق حساب فعلی مجاز است.
- در حالت رایگان فقط Subscriptionهای رایگان پیکربندی‌شده و فعال مجاز هستند.
- fallback به `decodeAllServerList()` از انتخاب خودکار حذف شد.
- Cache با اثر انگشت `mode + subscription GUIDs + server GUIDs` تفکیک شد.
- با تغییر پلن، Cache قبلی فوراً نامعتبر می‌شود.
- ردیف‌های قدیمی `BlueVPN Account` که URL متفاوت دارند غیرفعال می‌شوند.
- Broadcastهای Import به‌صورت Debounce/Coalesce پردازش می‌شوند.
- بارگذاری داخل `runCatching` قرار گرفت و Loading در همه حالت‌ها خاتمه می‌یابد.
- فهرست معتبر قبلی تا پایان Refresh نمایش داده می‌شود، ولی هرگز بین دو پلن به اشتراک گذاشته نمی‌شود.

## نتیجه

انتخاب خودکار Premium نمی‌تواند از سرور رایگان یا اشتراک قدیمی استفاده کند و انتخاب خودکار رایگان نیز به سرور Premium دسترسی ندارد. صفحه مکان‌ها در خطای Import یا Broadcastهای متوالی روی Loading باقی نمی‌ماند.
