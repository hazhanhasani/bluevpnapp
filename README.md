# BlueVPN 3.0.21 — تاریخ شمسی و ساعت تهران

این نسخه تمام تاریخ‌ها و زمان‌های قابل مشاهده در اپلیکیشن، API و پنل مدیریت را با تقویم جلالی و منطقه زمانی `Asia/Tehran` نمایش می‌دهد.

## اصل فنی مهم

زمان‌های دیتابیس، انقضای پرداخت، Webhook، نشست‌ها و محاسبات داخلی همچنان UTC استاندارد ذخیره می‌شوند تا منطق پرداخت و انقضا دچار خطا نشود. در کنار هر مقدار استاندارد، مقدار نمایشی فارسی مانند `expires_at_fa` ارائه می‌شود.

## تغییرات

- نمایش شمسی تاریخ پایان اشتراک در اندروید
- نمایش ساعت تهران با ارقام فارسی
- تبدیل تاریخ‌های کاربران، سفارش‌ها، BlueAI و اتصال‌های زنده در پنل مدیریت
- اضافه‌شدن فیلدهای فارسی تاریخ به API حساب، سفارش و داشبورد
- ثبت تاریخ شمسی تهران در پیام‌های GuardCore و خطاهای راه‌اندازی
- بدون Migration دیتابیس
