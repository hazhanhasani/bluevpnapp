گزارش اعتبارسنجی BlueVPN 3.0.5 Fast Connect
تاریخ: 2026-08-05

موارد بررسی‌شده:
- نسخه فعال پروژه: 3.0.5
- versionCode اندروید: 30005
- همگام‌سازی نسخه در branding/app.json، release.json، deployment-marker.json و validation-report.json
- حذف نسخه‌های ثابت از سرویس Python و User-Agent یکپارچه بر پایه release.json
- اصلاح GitHub Actions برای ساخت نخست با نسخه پروژه و افزایش خودکار نسخه در انتشارهای بعدی
- اعتبارسنجی نحوی YAML گردش‌کار GitHub Actions
- اعتبارسنجی نحوی فایل‌های Python با compileall
- اعتبارسنجی 21 محتوای Kotlin/XML تعبیه‌شده به صورت Base64
- کش کوتاه‌مدت فهرست سرورها و حذف پردازش تکراری هنگام رندر صفحه اصلی
- اجرای کارهای غیرضروری پس از اولین فریم برای کاهش صفحه سیاه شروع برنامه
- تست اینترنت First Response با سقف زمانی کوتاه‌تر و توقف پس از اولین پاسخ معتبر
- کاهش تأخیرهای ثابت اتصال، بررسی و Failover
- جلوگیری از رندر دوباره صفحه تنظیمات، سرورها و اشتراک در ورود اولیه

نکته:
این بسته منبع و گردش‌کار ساخت است. کامپایل نهایی APK و امضای آن توسط GitHub Actions انجام می‌شود.
