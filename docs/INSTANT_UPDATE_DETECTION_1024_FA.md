# BlueVPN 1.0.24 — تشخیص فوری بروزرسانی

## علت نمایش‌ندادن پیام

در نسخه قبلی:

- Backend آخرین GitHub Release را ۵ دقیقه Cache می‌کرد.
- برنامه پس از بررسی، تا یک ساعت دوباره درخواست نمی‌فرستاد.
- اگر Release پس از بازشدن برنامه منتشر می‌شد، تا اجرای مجدد یا پایان فاصله
  بررسی شناسایی نمی‌شد.
- در حالت دانلود خودکار فقط Toast کوتاه نمایش داده می‌شد.

## اصلاح

- Cache گیت‌هاب به ۱۵ ثانیه کاهش یافت.
- فاصله بررسی برنامه به ۳۰ ثانیه کاهش یافت.
- با بازگشت برنامه به Foreground، بروزرسانی دوباره بررسی می‌شود.
- بررسی دستی Backend را با `refresh=true` تازه می‌کند.
- هم Version Code و هم Version Name مقایسه می‌شوند.
- هنگام دانلود خودکار، پنجره واضح نسخه جدید نمایش داده می‌شود.
- دکمه «بررسی بروزرسانی» به تنظیمات اضافه شد.
- متن اشتباه «همگام‌سازی هر ۱ دقیقه» اصلاح شد.
