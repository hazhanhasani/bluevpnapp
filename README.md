# BlueVPN 3.0.15 — BluePay & Expiry Sync Fix

این نسخه مشکل نمایش اشتباه «پایان یافته» را با خروجی UTC استاندارد دارای `Z`، نمایش صریح پلن نامحدود و تحمل اختلاف ساعت دو دقیقه‌ای رفع می‌کند. تمدید پلن زمان‌دار از انتهای اعتبار معتبر قبلی محاسبه می‌شود.

پس از بازگشت از BluePay، مسیر `GET /api/v1/orders/{order_id}/check-after-success` حداکثر ۳۰ ثانیه و هر ۵ ثانیه وضعیت فاکتور را بررسی می‌کند. مبلغ‌های ریالی به تومان نرمال می‌شوند و هر اختلاف مبلغ، فعال‌سازی را متوقف و در لاگ اختصاصی ثبت می‌کند. تأیید با بیش از یک ساعت تأخیر یک روز اعتبار جبرانی می‌گیرد.

Build #63 پیش از Gradle به دلیل پیشروی شاخه متوقف شد. Workflow جدید ابتدا آخرین شاخه را دریافت می‌کند، Build قدیمی را لغو می‌کند و Pushهای metadata/generated source را با rebase و retry انجام می‌دهد.
