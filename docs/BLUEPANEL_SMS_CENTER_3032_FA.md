# مرکز کامل پیامک بلوپنل — نسخه 3.0.32

این نسخه روی پروژه کامل 3.0.31 ساخته شده و ۳۸ پترن ثبت‌شده برای برند «بلوپنل» را وارد هسته پروژه می‌کند.

## امکانات

- کاتالوگ ثابت ۳۸ پیام با نام متغیر، نوع و حداکثر طول دقیق
- پنل ثبت و فعال‌سازی مستقل کد هر پترن
- تست مستقیم هر پترن با شماره و JSON پارامترها
- صف ارسال دیتابیسی، جلوگیری از ارسال تکراری و Retry کنترل‌شده
- گزارش ۱۰۰ ارسال اخیر، خطای سرویس‌دهنده و تعداد تلاش‌ها
- اعلان خودکار برای ایجاد و انقضای فاکتور، پرداخت موفق یا ناموفق، فعال‌سازی، تمدید، ارتقا یا تغییر پلن
- اعلان ورود دستگاه جدید، تلاش مشکوک، تغییر شماره، مسدودی و رفع مسدودی
- اسکن ساعتی یادآوری پایان اشتراک، پایان اشتراک، کاهش حجم و پایان حجم
- ارسال عمومی امن برای اختلال، رفع اختلال، تعمیرات، نسخه جدید، آپدیت اجباری و اطلاعیه مدیریت
- API داخلی رویداد برای ماژول‌های کیف پول و تیکت که ممکن است بعداً یا در سرویس دیگری اجرا شوند

## راه‌اندازی

1. در پنل مدیریت وارد «تنظیمات پیامک» شوید و API Key و شماره فرستنده را ثبت کنید.
2. در تب «پترن‌ها» کد پترن فراز اس‌ام‌اس را مقابل هر پیام قرار دهید و همان پیام را فعال کنید.
3. «اعلان‌های خودکار» را فعال کنید.
4. یک پترن را با شماره آزمایشی تست کنید.
5. وضعیت ارسال را از تب «گزارش پیامک» بررسی کنید.

پترن ورود قبلی به‌صورت خودکار به `auth_otp` منتقل می‌شود و اطلاعات API رمزگذاری‌شده باقی می‌ماند.
