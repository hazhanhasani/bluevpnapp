# تثبیت لیست مکان‌ها در BlueVPN 3.0.77

در نسخه‌های قبلی، ورود به صفحه مکان‌ها هم‌زمان چند مسیر را اجرا می‌کرد: همگام‌سازی حساب، Import دوباره Subscription، Decode سرورها، Ping و دریافت لوکیشن ابری. v2rayNG هنگام به‌روزرسانی Subscription، فهرست MMKV را برای مدت کوتاهی خالی و سپس دوباره پر می‌کند. پاسخ خالی موقت جای Cache سالم را می‌گرفت و کاربر مشاهده می‌کرد که کشورها لحظه‌ای ظاهر و سپس ناپدید می‌شوند.

## تغییرات

- هویت Cache از فهرست متغیر GUID سرورها جدا شد و بر اساس نوع پلن و URL اشتراک ساخته می‌شود.
- Snapshot غیرخالی قبلی تا آماده‌شدن Snapshot جدید حفظ می‌شود.
- پاسخ خالی موقت اجازه جایگزینی فهرست سالم را ندارد.
- ورود به صفحه مکان‌ها، اشتراک Premium سالم و بدون تغییر را دوباره Import نمی‌کند.
- عملیات Reconcile و Import Subscription تک‌مسیره و قفل‌شده است.
- دکمه تازه‌سازی فقط یک Pipeline را اجرا می‌کند و دیگر Sync، Import، Decode و Ping را به‌طور هم‌زمان آغاز نمی‌کند.
- نتیجه بارگذاری متعلق به پلن قبلی در صورت تغییر Entitlement نادیده گرفته می‌شود.
- رابط کاربری هنگام Refresh، ردیف‌های موجود را قبل از آماده‌شدن Snapshot جدید حذف نمی‌کند.

این اصلاح جداسازی رایگان و Premium را تغییر نمی‌دهد؛ Cache قبلی تنها زمانی حفظ می‌شود که هویت همان Entitlement باقی مانده باشد. تغییر رایگان به Premium یا تغییر URL اشتراک، هویت جدیدی ایجاد می‌کند و فهرست قبلی نمایش داده نمی‌شود.
