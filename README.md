# BlueVPN 3.0.41

> نسخه 3.0.41 خطای «مشکل در تجزیه بسته» هنگام بروزرسانی داخلی را با نصب مستقیم از Android PackageInstaller Session رفع می‌کند.

## تغییر اصلی

- دانلود APK در حافظه خصوصی برنامه
- اعتبارسنجی اندازه، SHA-256، packageName، versionName، versionCode و امضای دیجیتال
- انتقال بایت‌های APK به PackageInstaller Session
- نمایش صفحه تأیید رسمی اندروید
- پیام دقیق برای ناسازگاری، اختلاف امضا، کمبود فضا یا لغو نصب
- FileProvider اختصاصی فقط به‌عنوان مسیر جایگزین دستگاه‌های OEM

تمام قابلیت‌ها و طراحی نسخه 3.0.40 حفظ شده‌اند.
