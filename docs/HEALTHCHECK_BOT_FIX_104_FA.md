# اصلاح Healthcheck و ربات — نسخه 1.0.4

## علت خطا

هنگام Deploy، Railway نسخه قبلی را تا موفق‌شدن Healthcheck نسخه جدید فعال
نگه می‌دارد. هر دو نسخه از یک توکن تلگرام استفاده می‌کنند.

در Runner قبلی ترتیب اجرا چنین بود:

1. اتصال و Polling ربات تلگرام
2. بالا آوردن Uvicorn و مسیر `/health`

در نتیجه تداخل Polling یا تأخیر تلگرام می‌توانست مانع بالا آمدن وب‌سرور شود و
Railway بعد از ۱۸۰ ثانیه Deployment را با `Healthcheck failure` رد کند.

## رفتار جدید

1. PostgreSQL و Migration بررسی می‌شوند.
2. Uvicorn فوراً روی متغیر `PORT` اجرا می‌شود.
3. پس از آماده‌شدن وب، ربات تلگرام در Task جداگانه شروع می‌شود.
4. اگر نسخه قبلی هنوز Polling می‌کند، نسخه جدید هر ۱۵ ثانیه دوباره تلاش می‌کند.
5. خطای تلگرام دیگر وب‌سایت، API، دیتابیس یا Healthcheck را از کار نمی‌اندازد.
6. پس از فعال‌شدن نسخه جدید و خاموش‌شدن نسخه قدیمی، Polling خودکار برقرار می‌شود.

این تغییر Backend است و APK جدید نیاز ندارد.
