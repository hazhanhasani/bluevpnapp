# BlueVPN 3.0.29 — بازیابی خودکار قفل ربات Deploy

این نسخه مشکل ماندن ربات روی پیام «یک نصب یا Build از قبل در حال اجراست» را رفع می‌کند.

- هر عملیات شناسه یکتا و Task مستقل دارد.
- Task قدیمی نمی‌تواند قفل عملیات جدید را پاک کند.
- دکمه `🔓 آزادسازی عملیات` و دستور `/unlock` اضافه شده است.
- Build منتظر GitHub Runner پس از ۱۵ دقیقه لغو و قفل ربات آزاد می‌شود.
- Watchdog قفل‌های محلی قدیمی را پاک می‌کند.
- ارسال ZIP جدید می‌تواند عملیات قبلیِ منتظر Runner را امن جایگزین کند.
- ورود شماره تماس و فراز اس‌ام‌اس و همه قابلیت‌های نسخه 3.0.28 حفظ شده‌اند.
