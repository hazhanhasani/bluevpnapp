# BlueVPN 3.0.30 — اجرای مستقیم GitHub Actions

این نسخه حالتی را رفع می‌کند که سورس و Commit جدید روی GitHub ثبت می‌شد اما Build جدید در Actions ساخته نمی‌شد و ربات همچنان آخرین Build قدیمی را نمایش می‌داد.

- بعد از تأیید Commit، ربات مستقیماً endpoint رسمی `workflow_dispatch` را اجرا می‌کند.
- ساخت APK دیگر فقط به رخداد `push` وابسته نیست.
- اگر Workflow غیرفعال باشد، ربات آن را فعال می‌کند.
- دکمه `🚀 ساخت فوری` آخرین Commit شاخه را بدون ساخت Commit خالی Build می‌کند.
- Runهای قدیمی قبل از درخواست جدید نادیده گرفته می‌شوند.
- بخش وضعیت، Commit فعلی شاخه و Commit آخرین Build را مقایسه می‌کند.
- بازیابی قفل، `/unlock` و Timeout مربوط به Runner حفظ شده‌اند.
- هیچ متغیر جدیدی لازم نیست؛ `GITHUB_TOKEN` فعلی باید مجوز `Actions: write` داشته باشد.
