BlueVPN 2.2.1 — GuardCore دستی از طریق ربات

این ZIP را مستقیم برای ربات Deploy ارسال کن.

رفتار نهایی:
- PasarGuard: ساخت و تمدید کاملاً خودکار
- Marzban: ساخت و تمدید کاملاً خودکار
- GuardCore: نیمه‌خودکار و فقط با Paste لینک Subscription

فرایند GuardCore:
1. کاربر پلن می‌خرد یا ادمین اشتراک را دستی فعال می‌کند.
2. PasarGuard و Marzban طبق روال خودکار فعال می‌شوند.
3. ربات برای ادمین پیام می‌فرستد و می‌پرسد GuardCore هم استفاده شود یا خیر.
4. با انتخاب «بله»، نام پیشنهادی کاربر، مدت، حجم و لینک ورود پنل نمایش داده می‌شود.
5. ادمین کاربر را در GuardCore می‌سازد و لینک ساب را برای ربات می‌فرستد.
6. ربات لینک را بررسی و به اشتراک تجمیعی همان مشتری اضافه می‌کند.
7. با انتخاب «خیر»، هیچ تغییری در GuardCore انجام نمی‌شود و سرویس خودکار کاربر باقی می‌ماند.

امکانات پشتیبان:
- صف درخواست‌های منتظر GuardCore در پنل وب
- ثبت لینک از پنل وب در صورت ری‌استارت ربات
- ارسال دوباره پیام درخواست به ربات
- تبدیل اتصال GuardCore قبلی از حالت API به حالت دستی
- اعتبارسنجی لینک ساب و جلوگیری از ثبت صفحه وب به‌جای Subscription
- حفظ لینک‌های قبلی هنگام تمدید
- عدم وابستگی GuardCore دستی به API Key یا رمز پنل

راه‌اندازی:
1. Deploy را انجام بده.
2. در پنل مدیریت، بخش GuardCore را باز کن.
3. یک پنل با روش «دستی از طریق ربات» بساز.
4. لینک ورود پنل، مثلاً https://app.solidlayerco.com را وارد کن.
5. آن GuardCore را روی پلن‌های موردنظر انتخاب کن.
6. Service ID در حالت دستی لازم نیست.
7. BOT_TOKEN و ADMIN_IDS باید روی Railway تنظیم باشند.
