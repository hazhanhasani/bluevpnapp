# BlueVPN 2.1.0 — Premium Smart Connect

## نسخه انتشار

- نخستین Build این بسته: `2.1.0` با Version Code `21000`
- Release بعدی: `2.1.1`
- سپس: `2.1.2` و به همین ترتیب
- شماره نسخه از آخرین GitHub Release سری 2.1 محاسبه می‌شود.

## طراحی جدید

- داشبورد اصلی بازطراحی‌شده با کارت وضعیت، امتیاز کیفیت، آمار زنده و تاریخچه
- رنگ‌بندی Premium و گرادینت‌های اختصاصی BlueVPN
- کارت‌های مدرن حساب، اشتراک و پلن‌ها
- پیام خوش‌آمدگویی مخصوص نسخه 2.1
- Fade کوتاه و سبک بین صفحات
- پیام بروزرسانی واضح‌تر و حرفه‌ای‌تر

## Smart Connect 2.1

سه پروفایل محلی اتصال اضافه شده است:

- متعادل: ترکیب پینگ، پایداری و مسیر جایگزین
- بازی: اولویت بالاتر برای کمترین پینگ
- پخش: اولویت بالاتر برای مسیرهای پایدار و علاقه‌مندی‌ها

رتبه‌بندی سرورها با این داده‌ها انجام می‌شود:

- پینگ ذخیره‌شده
- موفق یا ناموفق‌بودن تست
- وضعیت موقت در همان اجرای برنامه
- لوکیشن‌های علاقه‌مندی
- حالت انتخاب‌شده کاربر
- سابقه خطای اخیر

## لوکیشن‌ها

- ستاره‌دارکردن کشورها
- فیلتر فقط علاقه‌مندی‌ها
- امتیاز سلامت 0 تا 100 برای هر لوکیشن
- برچسب‌های عالی، خیلی خوب، خوب، متوسط، ضعیف و ناموفق
- نمایش فقط نام و پرچم لوکیشن؛ نام فنی سرور نمایش داده نمی‌شود

## تاریخچه اتصال

آخرین 12 اتصال موفق فقط روی همان دستگاه ذخیره می‌شود:

- لوکیشن
- پینگ
- امتیاز سلامت
- حالت اتصال
- زمان اتصال

در تنظیمات امکان مشاهده خلاصه و پاک‌کردن تاریخچه وجود دارد.

## موارد حفظ‌شده

- ورود پایدار و Refresh Token مقاوم در برابر درخواست هم‌زمان
- مخفی‌بودن پلن‌ها پیش از ورود
- همگام‌سازی فقط هنگام اجرای تازه برنامه
- لغو اتصال در زمان بررسی
- قطع اتصال فوری
- بروزرسانی خودکار از GitHub Releases
- ادغام PasarGuard و Marzban
- انتشار APK امضاشده برای arm64-v8a و armeabi-v7a
