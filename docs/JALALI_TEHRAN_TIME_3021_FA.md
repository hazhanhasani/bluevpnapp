# تاریخ شمسی و ساعت تهران در BlueVPN 3.0.21

## رفتار نهایی

تمام تاریخ‌ها و ساعت‌های قابل مشاهده برای مدیر و کاربر با تقویم جلالی، ارقام فارسی و منطقه زمانی `Asia/Tehran` نمایش داده می‌شوند.

نمونه:

```text
۱۴۰۵/۰۵/۱۵، ساعت ۱۵:۳۰
```

## جداسازی نمایش از منطق داخلی

برای جلوگیری از خرابی مهلت پرداخت، انقضای اشتراک، Webhook و نشست‌ها، زمان‌های اصلی دیتابیس همچنان UTC ذخیره می‌شوند. API در کنار مقدار استاندارد، مقدار نمایشی فارسی را نیز برمی‌گرداند:

```json
{
  "expires_at": "2026-08-06T20:30:00Z",
  "expires_at_fa": "۱۴۰۵/۰۵/۱۶، ساعت ۰۰:۰۰",
  "calendar": "jalali",
  "timezone": "Asia/Tehran"
}
```

## بخش‌های پوشش‌داده‌شده

- تاریخ پایان اشتراک در اپلیکیشن Android
- ساعت و تاریخ پنل مدیریت
- تاریخ کاربران و سفارش‌ها
- تاریخ رویدادها، خطاها و اتصال‌های زنده BlueAI
- API حساب، سفارش، وضعیت پرداخت و تنظیمات موبایل
- پیام‌های GuardCore در تلگرام
- وضعیت Startup و خطاهای راه‌اندازی
- Headerهای پاسخ HTTP برای اعلام تقویم و منطقه زمانی

## Headerهای پاسخ

```text
Content-Language: fa-IR
X-BlueVPN-Timezone: Asia/Tehran
X-BlueVPN-Calendar: jalali
```

## دیتابیس

این نسخه Migration دیتابیس ندارد. نوع و مقدار ستون‌های زمانی تغییر نکرده‌اند.
