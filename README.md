# BlueVPN 3.0.18 — BluePay Checkout Lifecycle

نسخه 3.0.18 مشکل بازشدن دوباره فاکتور قدیمی و منقضی BluePay را رفع می‌کند.

## رفتار جدید

- تا وقتی صفحه پرداخت باز است، فاکتور حداکثر ۳۰ دقیقه اعتبار دارد.
- وقتی کاربر از مرورگر پرداخت به BlueVPN برمی‌گردد، زمان خروج به Backend اعلام می‌شود.
- پس از خروج، همان فاکتور فقط ۵ دقیقه دیگر قابل بازگشت و استفاده است.
- بعد از ۵ دقیقه وضعیت محلی فاکتور `abandoned` می‌شود و خرید بعدی یک فاکتور و لینک تازه می‌سازد.
- پرداخت دیرهنگامِ واقعی حذف نمی‌شود و Webhook معتبر همچنان می‌تواند سفارش را بازیابی و فعال کند.
- زمان‌های `checkout_opened_at`، `checkout_last_seen_at` و `checkout_closed_at` در دیتابیس ذخیره می‌شوند.

Schema دیتابیس به نسخه 11 ارتقا یافته و Migration به‌صورت خودکار انجام می‌شود.
