BlueVPN Manager 4.0.21 — Responsive Admin Layout

هدف این نسخه: مرتب‌سازی و منسجم‌کردن Control Center مخصوصاً روی موبایل.

تغییرات اصلی:
- صفحه پلن‌ها از جدول چندستونه به کارت‌های مستقل تبدیل شد.
- هر کارت پلن: عنوان/وضعیت، قیمت، اعتبار، حجم، دستگاه و Providerها را به‌صورت خلاصه نشان می‌دهد.
- Routing هر پلن داخل بخش بازشونده قرار گرفت و فقط هنگام نیاز باز می‌شود.
- min-width ثابت 620px از فرم Routing حذف شد؛ عامل اصلی بیرون‌زدگی صفحه در موبایل.
- فرم ساخت پلن به سه لایه تقسیم شد: مشخصات اصلی، مسیر سرویس، تنظیمات پیشرفته.
- Group ID و Service ID داخل Advanced Options جمع شدند تا صفحه شلوغ نشود.
- جدول‌های bvc-table در موبایل با JavaScript به کارت‌های دارای data-label تبدیل می‌شوند؛ دسکتاپ همچنان جدول عادی است.
- white-space:nowrap سراسری موبایل حذف شد تا متن/فرم‌ها از کادر بیرون نزنند.
- Hero و فاصله‌گذاری صفحات Control Center روی موبایل جمع‌وجورتر شد.
- تمام قابلیت‌های نسخه 4.0.20 و اصلاحات GitHub/ربات حفظ شده‌اند.
