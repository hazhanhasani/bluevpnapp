# صفحه عمومی بلوپنل — نسخه 3.0.33

این نسخه مسیر اصلی دامنه را از انتقال مستقیم به مدیریت، به یک وب‌سایت عمومی و شفاف تبدیل می‌کند.

## مسیرهای عمومی

- `/` صفحه معرفی خدمات
- `/terms` قوانین و مقررات
- `/privacy` حریم خصوصی
- `/refund-policy` شرایط بررسی و بازگشت وجه
- `/contact` راه‌های ارتباط
- `/robots.txt` تنظیمات موتور جست‌وجو
- `/sitemap.xml` نقشه سایت

پنل مدیریت همچنان در `/admin` و `/admin/login` در دسترس است.

## محتوای صفحه

صفحه فقط قابلیت‌های واقعی پروژه را معرفی می‌کند: مدیریت حساب و اشتراک، سفارش و صورتحساب، پرداخت، اعلان پیامکی، امنیت حساب، پشتیبانی و یکپارچه‌سازی API. اطلاعات حقوقی و تماس از متغیرهای Railway خوانده می‌شوند.

## متغیرهای Railway

```env
PUBLIC_SITE_URL=https://bot.blluepanel.ir
PUBLIC_SITE_NAME=بلوپنل
PUBLIC_SITE_DESCRIPTION=سامانه‌ای برای مدیریت حساب کاربران، سفارش‌ها، صورتحساب‌ها، اعلان‌های پیامکی و پشتیبانی خدمات دیجیتال.
PUBLIC_SUPPORT_URL=
PUBLIC_SUPPORT_PHONE=
PUBLIC_SUPPORT_EMAIL=
PUBLIC_BUSINESS_OWNER=
PUBLIC_BUSINESS_ADDRESS=
PUBLIC_BUSINESS_HOURS=شنبه تا پنجشنبه، ساعت ۹ تا ۱۸
ENAMAD_VERIFY_URL=
ENAMAD_LOGO_URL=
PUBLIC_API_DOCS=false
```

برای نمایش نشان اعتماد، دو مقدار آخر باید دقیقاً از کد رسمی نشان استخراج شوند. آدرس ساختگی یا تصویر غیررسمی قرار ندهید.

## رفتار دامنه

بعد از Deploy، بازکردن `https://bot.blluepanel.ir/` صفحه عمومی را نمایش می‌دهد. مسیر سلامت، API موبایل و مدیریت تغییری نکرده‌اند.

## مستندات API

مسیرهای `/docs`، `/redoc` و `/openapi.json` در محیط عمومی به‌صورت پیش‌فرض غیرفعال‌اند. فقط برای محیط توسعه و با `PUBLIC_API_DOCS=true` فعال شوند.
