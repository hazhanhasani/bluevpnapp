BlueVPN Site 1.0.7 — Elementor Edition

1) افزونه Elementor را نصب و فعال کنید.
2) پوسته BlueVPN Site را نصب/بروزرسانی کنید.
3) از منوی «نمایش ← BlueVPN Elementor» وارد شوید.
4) خانه، پلن‌ها، دانلود، حساب، پشتیبانی، Header و Footer را با Elementor ویرایش کنید.
5) اطلاعات داینامیک حساب/OTP/پلن‌ها از BlueVPN Manager خوانده می‌شوند و با طراحی Elementor تداخلی ندارند.
6) آپدیت خودکار پوسته طراحی Elementor شما را بازنویسی نمی‌کند. تنها دکمه «بازسازی قالب‌های Elementor» چیدمان پیش‌فرض را عمداً بازنشانی می‌کند.

Elementor Pro الزامی نیست. اگر Pro فعال باشد، Theme Builder می‌تواند Header/Footer استاندارد Elementor را جایگزین Templateهای پیش‌فرض BlueVPN کند.
