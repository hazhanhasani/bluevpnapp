BlueVPN Site 1.1.0 — Elementor + Real App UI

صفحه خانه در نسخه 1.1.0 به یک لندینگ Product-led بازطراحی شده است.

نکات مهم:
- صفحه خانه در Elementor با ویجت «BlueVPN • صفحه اصلی حرفه‌ای» ساخته می‌شود.
- مهاجرت از Seed قبلی فقط یک‌بار صفحه Home را به طراحی جدید ارتقا می‌دهد؛ صفحات حساب، دانلود، پلن و پشتیبانی دست‌نخورده می‌مانند.
- تصاویر ساختگی موبایل در لندینگ جدید استفاده نمی‌شوند.
- مسیر: نمایش > سفارشی‌سازی > BlueVPN • تصاویر واقعی اپلیکیشن
  1) صفحه اصلی / اتصال
  2) صفحه لوکیشن‌ها
  3) صفحه حساب / اشتراک
  4) صفحه پشتیبانی
- اگر تصویر دوم/سوم انتخاب نشده باشد، قالب از تصویر واقعی اصلی به‌عنوان fallback استفاده می‌کند.
- موبایل اکنون Native responsive است و viewport دسکتاپ 1080 اجباری نیست.
- اگر نیاز به بازسازی صفحه Elementor بود: نمایش > BlueVPN Elementor > بازسازی قالب‌های Elementor.
