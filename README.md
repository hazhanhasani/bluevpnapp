# BlueVPN 3.0.22 — بازیابی وضعیت اشتراک

این نسخه مشکل غیرفعال‌شدن اشتراک‌های معتبر بعد از Restart یا همگام‌سازی ناقص پنل را رفع می‌کند.

- خطای موقت PasarGuard، Marzban یا GuardCore دیگر وضعیت معتبر قبلی را پاک نمی‌کند.
- پاسخ موفق پنل که فیلد `status` ندارد، فعال در نظر گرفته می‌شود.
- تاریخ انقضا، حجم و مصرف قبلی هنگام پاسخ ناقص حفظ می‌شوند.
- هنگام Startup حساب‌های معتبرِ اشتباهاً غیرفعال‌شده بازیابی می‌شوند.
- در پنل مدیریت دکمه «بازیابی اشتراک‌های فعال» اضافه شده است.
- تاریخ‌های نمایشی همچنان شمسی و Asia/Tehran هستند؛ محاسبات داخلی و ساعت فرایند UTC باقی می‌مانند.
