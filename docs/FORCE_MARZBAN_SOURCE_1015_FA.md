- Version Code: 29

## علت مشاهده فقط ۱۸ سرور PasarGuard

مسیر عمومی `/sub/<token>` مستقیماً ادغام را اجرا می‌کرد. اگر کاربر هنوز در
Marzban ساخته نشده بود یا پلن قدیمی `marzban_panel_id` نداشت، بخش Marzban
اصلاً وارد مرحله ادغام نمی‌شد.

## اصلاح

- قبل از هر پاسخ `/sub/`، حساب و هر دو پنل همگام می‌شوند.
- اگر کاربر Marzban وجود نداشته باشد، همان لحظه ساخته می‌شود.
- اگر فقط یک پنل Marzban فعال باشد، خودکار به پلن قدیمی متصل می‌شود.
- اگر چند Marzban فعال باشد، مدیر باید یکی را برای پلن انتخاب کند.
- لینک‌های مستقیم API Marzban همچنان اولویت دارند.
- تعداد کانفیگ هر منبع جداگانه محاسبه می‌شود.
- در مدیریت کاربران دکمه «بررسی تعداد منابع» اضافه شده است.
- خروجی نمونه: PasarGuard: 18، Marzban: 12، مجموع: 30.
- ربات Deploy از Commit خالی و Push استفاده می‌کند و workflow_dispatch ندارد.
