# BlueVPN 3.0.39

نسخه کامل BlueVPN با رابط مینیمال الهام‌گرفته از ساختار JumpJump، بدون کپی فایل یا برند آن.

## تغییرات اصلی

- تم تیره، روشن و هماهنگ با دستگاه
- صفحه اصلی بدون نمایش پینگ، دانلود، آپلود یا حالت‌های بازی و استریم
- هوشمندی انتخاب مسیر کاملاً در پس‌زمینه
- کلید اتصال کشویی پایدار با نماد پاور اختصاصی
- بازطراحی ورود، ثبت‌نام، تنظیمات و مکان‌ها
- حذف متن‌های فنی از رابط و اعلان‌های کاربر
- انتخاب لحظه‌ای بهترین مسیر و حافظه مسیرهای موفق
- تشخیص پس‌زمینه کشور خروجی از Check-Host بدون نمایش متن فنی
- ارتقای خودکار دیتابیس به Schema 15

ساخت APK نهایی توسط GitHub Actions و سورس upstream انجام می‌شود.
