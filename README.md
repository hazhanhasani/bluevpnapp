# BlueVPN 3.0.24 — تشخیص قطعی اشتراک فعال

این نسخه مشکل نمایش «نیاز به تمدید» برای حسابی که واقعاً اشتراک فعال دارد را برطرف می‌کند.

- آخرین سفارش با وضعیت `activated` به‌عنوان منبع پایدار اعتبار اشتراک بررسی می‌شود.
- کش حساب بعد از نصب نسخه جدید خودکار بی‌اعتبار می‌شود.
- اگر وضعیت محلی غیرفعال باشد، فاصله پنج‌دقیقه‌ای Sync نادیده گرفته می‌شود.
- بازگشت از صفحه حساب یا پرداخت، فوراً همگام‌سازی اجباری انجام می‌دهد.
- صفحه اشتراک در اولین بازشدن وضعیت واقعی را از Backend دریافت می‌کند.
- پاسخ API شامل `entitlement_active`، `active_reason` و `remaining_seconds` است.
- وضعیت‌های صریح `disabled`، `blocked` و `expired` همچنان محترم شمرده می‌شوند و اشتباهی فعال نمی‌شوند.
- تاریخ‌های نمایشی شمسی و Asia/Tehran هستند؛ محاسبات داخلی روی UTC باقی می‌مانند.
