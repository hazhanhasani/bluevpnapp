# BlueVPN 3.0.12 — Admin Security Dashboard

نسخه اندروید و پنل مدیریت BlueVPN با هسته هوشمند مسیر.

## قابلیت‌های واقعی این بسته

- PasarGuard و Marzban خودکار، GuardCore دستی از طریق ربات
- یادگیری شخصی از مدت اتصال، موفقیت و شکست هر مسیر
- یادگیری جمعی ناشناس بر اساس اپراتور، Wi-Fi/موبایل، ساعت و حالت اتصال
- امتیاز BlueAI برای مرتب‌سازی سرورها
- ترمیم خودکار پس از دو افت کیفیت متوالی
- داشبورد BlueAI داخل اندروید
- مرکز فرمان هوشمند در پنل مدیریت
- بازخورد و گزارش فنی کاربر
- کنترل روشن/خاموش جمع‌آوری شاخص‌های فنی
- عدم جمع‌آوری محتوای ترافیک یا مقصدها
- نسخه‌گذاری خودکار 3.0.0، 3.0.1 و ...

## نکته انتشار

ساختار و Syntax بررسی شده‌اند. کامپایل APK نهایی در GitHub Actions انجام می‌شود.

## BlueVPN 3.0.8

- رفع `telegram.error.TimedOut` هنگام `get_me()` در Railway

- Retry پلکانی ۱۰ تا ۱۲۰ ثانیه و `bootstrap_retries=5`
- بستن ایمن HTTP Client حتی وقتی `initialize()` نیمه‌کاره شکست بخورد
- هشدار Telegram فقط پس از چند خطای موقت متوالی
- نمایش صحیح وضعیت PostgreSQL در `/startup-status`
- نسخه اندروید و Backend: `3.0.8` / `30008`

## BlueVPN 3.0.9

- GitHub Release روی Commit تأییدشده سورس ساخته می‌شود و لینک Commit در پیام تلگرام نمایش داده می‌شود.
- نسخه اندروید و Backend: `3.0.9` / `30009`

## BlueVPN 3.0.10

- امتیازدهی نمایی با نیمه‌عمر ۲ ساعته برای اولویت‌دادن به رخدادهای تازه
- جریمه شدید و غیرخطی برای Jitter بالا و Packet Loss
- Circuit Breaker اختصاصی هر اپراتور؛ خرابی همراه اول مسیر را برای ایرانسل نمی‌بندد
- Confidence مبتنی بر Wilson lower bound و تعداد نمونه‌های مؤثر
- پنجره محدود ۴۸ ساعته/۶۰۰ رویداد برای حفظ سرعت API
- نسخه Backend و Android: `3.0.10` / `30010`


## BlueVPN 3.0.11

- افزودن مجوز `CHANGE_NETWORK_STATE` برای استفاده مجاز از شبکه فیزیکی زیر VPN
- تلاش خودکار مسیر مستقیم دستگاه و سپس مسیر عادی/تونل فعال بدون نیاز به قطع VPN
- حذف نمایش خطای خام سیستمی و جایگزینی با پیام فارسی قابل فهم
- جلوگیری از شکست کامل دانلود صرفاً به‌دلیل محدودیت bindSocket در بعضی رام‌های Android و MIUI
- نسخه Backend و Android: `3.0.11` / `30011`

## BlueVPN 3.0.12

- بازطراحی پنل مدیریت با Dark Glass، فونت Vazirmatn و آیکون‌های SVG داخلی
- نمودارهای دایره‌ای زنده برای نرخ موفقیت هر اپراتور بدون کتابخانه خارجی
- Rate Limit مبتنی بر IP برای ثبت‌نام، ورود کاربران و ورود مدیر
- چرخش Session مدیر پس از ورود و Cookie امن با SameSite=Strict
- Endpoint امن و CSRF-protected برای دانلود ZIP پشتیبان دیتابیس
- پشتیبانی از `pg_dump` برای PostgreSQL و Backup سازگار برای SQLite
- قرار دادن Manifest، شمارش جدول‌ها و SHA-256 داخل فایل پشتیبان بدون افشای رمز دیتابیس
- نسخه Backend و Android: `3.0.12` / `30012`
