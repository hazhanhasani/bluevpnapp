BlueVPN 4.0.15 — WordPress Telegram Bot Cutover

این نسخه Runtime ربات BlueVPN را از Railway به WordPress/MySQL منتقل می‌کند.

موارد منتقل‌شده:
- Telegram Webhook روی REST API وردپرس (بدون polling و worker دائمی Railway)
- BOT_TOKEN / GITHUB_TOKEN / ADMIN_IDS و تنظیمات Build از Migration Bridge امن
- دریافت ZIP از Telegram و صف Job داخل MySQL
- اعمال ZIP روی GitHub با Git Data API بدون نیاز به git/Python/Docker روی هاست وردپرس
- Workflow Dispatch و پیگیری GitHub Actions
- وضعیت، Build فوری، Unlock، آخرین APK و بررسی Secretهای امضا
- صف دستی GuardCore و ثبت لینک Subscription از داخل ربات
- جداول bluevpn_bot_settings و bluevpn_bot_jobs

Cutover پیشنهادی:
1) ابتدا server/wordpress_migration_bridge.py این نسخه روی Railway deploy شود.
2) افزونه BlueVPN Manager 4.0.15 روی WordPress بروزرسانی شود.
3) Migration/Final Verify اجرا شود؛ Runtime secrets ربات خودکار وارد WordPress می‌شود.
4) از BlueVPN > ربات تلگرام، Test و Webhook status را بررسی کنید.
5) /start، Build فوری، ZIP deploy، Latest APK و GuardCore queue تست شوند.
6) بعد از موفقیت تست‌ها، Railway runtime ربات را خاموش کنید.

نکته امنیتی:
Secretها در خروجی Log یا UI نمایش داده نمی‌شوند و سمت WordPress دوباره رمزگذاری می‌شوند.
