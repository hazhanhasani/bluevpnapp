# BlueVPN 3.0.36 — رفع خطای Build ورود ایمیلی

این نسخه خطای `Unresolved reference password` در `BlueVpnSubscriptionsActivity.kt` را برطرف می‌کند. شنونده کلید پایان اکنون بعد از ساخته‌شدن فیلد رمز ثبت می‌شود؛ بنابراین متغیر در زمان مقداردهی اولیه به خودش ارجاع نمی‌دهد.

ورود و ثبت‌نام ایمیلی در کنار پیامک و لینک ساب سراسری پنل سوم برای کاربران قدیمی و جدید، همراه با قطع دسترسی پس از پایان اشتراک، بدون تغییر حفظ شده‌اند.
