# BlueVPN 3.0.37 — رابط مینیمال حرفه‌ای

این نسخه رابط اندروید BlueVPN را با الهام از ساختار ساده و متمرکز برنامه‌های مدرن VPN بازطراحی می‌کند، بدون کپی نام یا دارایی‌های JumpJump.

## تغییرات اصلی

- صفحه اصلی بدون اسکرول در ابعاد معمول موبایل
- کنترل اتصال کپسولی با دکمه متحرک
- نمایش فشرده پینگ، زمان اتصال، دانلود و آپلود
- کارت ثابت انتخاب سرور
- نمایش حجم و زمان باقی‌مانده بدون بنر تبلیغاتی
- صفحه مکان‌ها با تب‌های «مکان‌ها»، «مورد علاقه» و «اخیر»
- انتخاب خودکار پیش‌فرض و جست‌وجوی مکان‌ها
- حفظ ورود ایمیلی/پیامکی و پنل سوم سراسری
