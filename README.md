# BlueVPN 3.0.6 Build Fix

نسخه اندروید و پنل مدیریت BlueVPN با هسته هوشمند مسیر.

## قابلیت‌های واقعی این بسته

- PasarGuard و Marzban خودکار، GuardCore دستی از طریق ربات
- یادگیری شخصی از مدت اتصال، موفقیت و شکست هر مسیر
- یادگیری جمعی ناشناس بر اساس اپراتور، Wi-Fi/موبایل، ساعت و حالت اتصال
- امتیاز BlueAI برای مرتب‌سازی سرورها
- ترمیم خودکار پس از دو افت کیفیت متوالی
- داشبورد BlueAI داخل اندروید
- مرکز فرمان هوشمند در پنل مدیریت
- بازخورد و گزارش فنی کاربر
- کنترل روشن/خاموش جمع‌آوری شاخص‌های فنی
- عدم جمع‌آوری محتوای ترافیک یا مقصدها
- نسخه‌گذاری خودکار 3.0.0، 3.0.1 و ...

## نکته انتشار

ساختار و Syntax بررسی شده‌اند. کامپایل APK نهایی در GitHub Actions انجام می‌شود.


## 3.0.1
تشخیص سیم‌کارت فعال دیتا، BlueAI زنده، همگام‌سازی غیرمسدودکننده، صفحه اصلی ساده و تب‌های واقعی پنل مدیریت.


## BlueVPN 3.0.2

دانلودر داخلی APK با نمایش پیشرفت، ادامه اتصال VPN و اجرای خودکار نصب‌کننده.


## BlueVPN 3.0.5

- نمایش سریع‌تر صفحه اصلی در اجرای سرد و حذف صفحه سیاه طولانی
- کش کوتاه‌مدت فهرست سرورها و رتبه‌بندی از پیش محاسبه‌شده
- تأیید اتصال با اولین پاسخ موفق، بدون انتظار برای تمام سایت‌های تست
- کاهش زمان توقف/شروع هسته و تعویض مسیر
- حذف رندر و بررسی بروزرسانی تکراری هنگام ورود به صفحات
- نسخه واحد در اندروید، API، Health Check و User-Agentها
- اولین Build این بسته 3.0.5 است و Buildهای بعدی از آخرین GitHub Release افزایش می‌یابند


## BlueVPN 3.0.6

- رفع خطای Kotlin در `ExecutorCompletionService.submit<Long?>`
- استفاده از `completion.submit { ... }` با استنتاج صحیح نوع `Long?`
- افزودن کنترل خودکار برای جلوگیری از بازگشت همین خطا در Buildهای بعدی
- حفظ بهینه‌سازی‌های سرعت اتصال و اجرای نسخه 3.0.5
- اولین Build این بسته 3.0.6 است و نسخه‌های بعدی از آخرین GitHub Release افزایش می‌یابند
