# بهینه‌سازی حرارت و باتری BlueVPN 3.0.19

## مشکل
نسخه 3.0.18 هنگام اتصال چند مسیر مستقل برای Heartbeat، تست سلامت و Real Ping اجرا می‌کرد. تابع اثبات تونل نیز چهار درخواست را به‌صورت موازی باز می‌کرد. این وضعیت به‌خصوص روی اینترنت موبایل باعث Wake-up مکرر رادیو، مصرف CPU و داغ‌شدن دستگاه می‌شد.

## اصلاحات
- مالکیت Heartbeat فقط در `BlueVpnLiveReporter` قرار گرفت.
- زمان‌بندی تطبیقی: ۷۵ ثانیه در حالت تعاملی، ۹۰ ثانیه با صفحه خاموش و ۱۲۰ ثانیه در Power Saver.
- درخواست‌های اثبات تونل ترتیبی و First-success شدند.
- کش کوتاه‌مدت اثبات تونل با بررسی مجدد VPN Transport اضافه شد.
- Heartbeat و Real Ping تکراری از `BlueVpnHomeActivity` حذف شد.
- نرخ بروزرسانی UI از یک ثانیه به دو ثانیه کاهش یافت.
- انیمیشن دائمی Orb در حالت Connected متوقف شد.
- TTL اتصال زنده به ۱۸۰ ثانیه و حداکثر سن اثبات به ۱۳۰ ثانیه تغییر کرد تا زمان‌بندی کم‌مصرف پایدار بماند.

هیچ Migration دیتابیسی لازم نیست.
