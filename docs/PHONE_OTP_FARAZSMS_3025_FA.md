# ورود شماره تماس با فراز اس‌ام‌اس — BlueVPN 3.0.25

## رفتار ورود

در نسخه 3.0.25 ورود و ثبت‌نام با ایمیل و رمز عبور برای اپلیکیشن غیرفعال شده است. کاربر شماره موبایل ایران را وارد می‌کند، کد یک‌بارمصرف دریافت می‌کند و پس از تأیید، حساب موجود پیدا یا حساب جدید ساخته می‌شود.

حساب‌های قدیمی ایمیلی حذف نمی‌شوند. کاربر قدیمی که هنوز نشست معتبر دارد، یک‌بار شماره تماس خود را داخل صفحه «حساب و اشتراک» تأیید می‌کند. مدیر نیز می‌تواند شماره یک حساب قدیمی را از بخش کاربران ثبت کند.

## تنظیم فراز اس‌ام‌اس

اطلاعات پیامک داخل پنل مدیریت و بخش «پیامک و ورود» ذخیره می‌شود و نیازی به متغیر Railway ندارد:

- Base URL: `https://edge.ippanel.com/v1`
- API Key
- شماره فرستنده متصل به حساب
- کد پترن تأییدشده
- نام پارامتر پترن؛ معمولاً `code`
- تعداد رقم، اعتبار کد و فاصله ارسال مجدد

نمونه متن پترن:

```text
کد ورود BlueVPN: %code%
این کد را در اختیار دیگران قرار ندهید.
```

نام جایگذار واقعی پترن باید دقیقاً با «نام پارامتر کد» در پنل BlueVPN برابر باشد.

## کنترل‌های امنیتی

- کد OTP به‌صورت خام در دیتابیس ذخیره نمی‌شود.
- کد به شماره، دستگاه، هدف درخواست و شناسه Challenge متصل است.
- هر کد یک‌بارمصرف و زمان‌دار است.
- تلاش ناموفق محدود است.
- ارسال مجدد دارای Cooldown است.
- محدودیت درخواست بر اساس IP و هش شماره تماس اعمال می‌شود.
- API Key پیامک با کلید رمزگذاری پروژه ذخیره می‌شود.
- کد جدید، Challenge استفاده‌نشده قبلی را باطل می‌کند.

## مسیرهای API

```text
POST /api/v1/auth/otp/request
POST /api/v1/auth/otp/verify
POST /api/v1/account/phone/otp/request
POST /api/v1/account/phone/otp/verify
```

دو مسیر اول برای ورود یا ثبت‌نام و دو مسیر دوم برای اتصال شماره تماس به حساب قدیمی هستند.

## Migration

Schema دیتابیس به نسخه 12 ارتقا یافته است. ستون‌های `phone`، `phone_verified_at` و `auth_method` به کاربران افزوده می‌شوند و جدول‌های `otp_challenges` و `sms_settings` به‌صورت خودکار ساخته می‌شوند. اطلاعات اشتراک، سفارش، دستگاه و نشست کاربران قبلی حفظ می‌شود.
