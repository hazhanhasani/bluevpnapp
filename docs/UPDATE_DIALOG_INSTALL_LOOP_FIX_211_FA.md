# BlueVPN 2.1.1

## اصلاح تکرار نصب

نسخه قبلی شناسه دانلود کامل‌شده را نگه می‌داشت و با هر بررسی مجدد،
صفحه نصب Android دوباره باز می‌شد. در این نسخه:

- صفحه نصب برای هر نسخه فقط یک‌بار خودکار باز می‌شود.
- بعد از نصب نسخه جدید، تمام وضعیت دانلود و بروزرسانی قبلی پاک می‌شود.
- نسخه قدیمی‌تر حتی با Version Code اشتباه به‌عنوان بروزرسانی نمایش داده نمی‌شود.
- بروزرسانی اختیاری با انتخاب «بعداً» تا ۶ ساعت دوباره مزاحم نمی‌شود.

## طراحی

پیام‌های داخل BlueVPN با کارت اختصاصی تیره، لوگو، عنوان رنگی،
نوار پیشرفت و دکمه‌های گرد بازطراحی شده‌اند.

صفحه نهایی «آیا می‌خواهید این برنامه را بروزرسانی کنید؟» متعلق به
Package Installer خود Android است و ظاهر آن توسط برنامه قابل تغییر نیست.
