# BlueVPN 3.0.31 — ساخت قطعی APK از ربات Deploy

این نسخه حالتی را رفع می‌کند که سورس جدید روی GitHub ثبت می‌شد، اما وضعیت ربات همچنان آخرین Build قدیمی را نشان می‌داد و Run جدید ساخته نمی‌شد.

- ربات ابتدا از `repository_dispatch` استفاده می‌کند؛ این روش با همان مجوز `Contents: write` موردنیاز برای آپلود فایل‌ها کار می‌کند.
- اگر GitHub در ۳۰ ثانیه Run جدید نسازد، ربات خودکار `workflow_dispatch` را به‌عنوان روش دوم امتحان می‌کند.
- Workflow رویداد `repository_dispatch` با نوع `bluevpn_build` را می‌پذیرد.
- SHA دقیق Commit فعلی همراه درخواست ارسال و همان Commit در Runner بررسی و Build می‌شود.
- Buildهای قدیمی با Build جدید اشتباه گرفته نمی‌شوند.
- هیچ متغیر Railway جدیدی لازم نیست.
- قفل خودکار، `/unlock`، تایم‌اوت Runner و ورود شماره تماس/FarazSMS نسخه‌های قبلی حفظ شده‌اند.
