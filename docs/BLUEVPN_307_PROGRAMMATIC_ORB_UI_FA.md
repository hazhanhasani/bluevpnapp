# BlueVPN 3.0.7 — بازطراحی Programmatic Orb UI

- صفحه اصلی دیگر از `activity_bluevpn_home.xml` Inflate نمی‌شود و با `createScreen()` ساخته می‌شود.
- دکمه اتصال به Orb دایره‌ای با چهار حالت آماده، در حال اتصال، متصل و خطا تبدیل شد.
- پالس سبک با `ValueAnimator` فقط در حالت اتصال/متصل اجرا می‌شود و در `onDestroy` متوقف می‌شود.
- کارت‌های دانلود/آپلود و پینگ واقعی به‌صورت شیشه‌ای اطراف Orb نمایش داده می‌شوند.
- پس‌زمینه `bluevpn_screen_background` به Mesh Gradient چندلایه سرمه‌ای، بنفش و فیروزه‌ای ارتقا یافت.
- تمام IDهای قبلی حفظ شده‌اند تا منطق اتصال، BlueAI، اشتراک، سرورها و تنظیمات بدون شکست کار کنند.
- نسخه پروژه و اندروید: `3.0.7` / `30007`.
