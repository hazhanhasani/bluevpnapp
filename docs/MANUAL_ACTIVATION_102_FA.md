# فعال‌سازی دستی اشتراک — BlueVPN Platform 1.0.2

## کاربرد

مدیر می‌تواند برای حساب ثبت‌شده، بدون ساخت فاکتور BluePay، یک پلن را مستقیم
فعال یا تمدید کند. این قابلیت برای پرداخت نقدی، هدیه، تست و جبران سرویس مناسب است.

## مسیر پنل

`پنل مدیریت → فعال‌سازی دستی`

مدیر وارد می‌کند:

- ایمیل حساب کاربر
- پلن
- یادداشت اختیاری

همچنین در جدول کاربران، برای هر حساب یک منوی «فعال‌سازی دستی» وجود دارد.

## رفتار

1. کاربر و پلن بررسی می‌شوند.
2. یک سفارش حسابرسی با کد `MANUAL-...` و مبلغ صفر ساخته می‌شود.
3. ساخت یا تمدید کاربر با API پاسارگارد انجام می‌شود.
4. مدت پلن از انتهای اعتبار فعلی افزوده می‌شود؛ اگر منقضی شده باشد از زمان فعلی.
5. حجم، گروه‌ها و محدودیت ۱ یا ۲ دستگاه مطابق پلن اعمال می‌شوند.
6. اگر محدودیت از ۲ به ۱ کاهش یابد، دستگاه‌های اضافه غیرفعال و نشستشان لغو می‌شود.
7. برنامه کاربر در اجرای بعدی یا بازگشت به برنامه، اشتراک را خودکار همگام می‌کند.
8. نتیجه در بخش «پرداخت و فعال‌سازی» با نشان «دستی» باقی می‌ماند.

این بروزرسانی Backend و پنل مدیریت است و تغییر Android جدیدی ندارد.
