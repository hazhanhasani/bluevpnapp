# BlueVPN 2.2.2 — رفع ارسال‌نشدن پیام GuardCore

علت اصلی این بود که درخواست دستی فقط وقتی ساخته می‌شد که GuardCore مستقیماً داخل همان پلن انتخاب شده بود.

در نسخه 2.2.2:

- اگر پلن GuardCore مشخصی نداشته باشد، اولین پنل GuardCore دستی فعال به‌عنوان پیشنهاد اختیاری استفاده می‌شود.
- بعد از خرید و بعد از فعال‌سازی دستی مدیر، پیام بله/خیر ساخته می‌شود.
- سفارش‌های فعال‌شده ۷۲ ساعت اخیر که پیامشان جا افتاده، هنگام شروع ربات بازیابی می‌شوند.
- درخواست‌های ارسال‌نشده هر ۶۰ ثانیه دوباره تلاش می‌شوند.
- دلیل خطای ارسال در صف پنل ذخیره می‌شود.
- PasarGuard و Marzban همچنان کاملاً خودکار هستند.
