# BlueVPN 1.0.16 — دریافت از ساب واقعی Marzban

- Android: 1.0.16
- Version Code: 30
- Build ID: 20260804131753

## علت نسخه قبلی

در نسخه قبلی اگر API مرزبان فیلد `links` داشت، کد دیگر لینک
`subscription_url` را دانلود نمی‌کرد. بنابراین خروجی الزاماً از ساب واقعی
مرزبان نبود و ساب فقط در حالت نبودن links استفاده می‌شد.

## اصلاح

- ابتدا خود `subscription_url` کاربر Marzban دانلود می‌شود.
- درخواست با User-Agent دقیق v2rayNG ارسال می‌شود.
- اگر قالب HTML اشتراک برگردد، به‌عنوان خطای واضح گزارش می‌شود.
- لینک‌های ساب قبل از لینک‌های API قرار می‌گیرند.
- لینک‌های API فقط مکمل و مسیر پشتیبان هستند.
- کانفیگ‌های تکراری بین ساب و API حذف می‌شوند.
- Cache ساب نهایی غیرفعال است.
- مدیریت تعداد ساب واقعی، API، PasarGuard و مجموع را جدا نشان می‌دهد.
