# BlueVPN 3.0.10 — ارتقای منطق BlueAI

## تغییرات

- **Time Decay:** رویدادها با نیمه‌عمر ۲ ساعت وزن می‌گیرند؛ یک رخداد یک‌ساعته حدود ۷۰٪ وزن دارد اما رخداد ۲۴ ساعت قبل کمتر از ۰٫۰۳٪.
- **Jitter Penalty:** جریمه نوسان پینگ غیرخطی است و در Jitter شدید می‌تواند تا ۴۴ امتیاز کم کند.
- **Operator Sensitivity:** Aggregate هر اپراتور جداست. اگر حداقل ۱۰ نمونه کل، ۵ نمونه مؤثر اخیر و نرخ شکست اخیر حداقل ۷۲٪ باشد، مسیر فقط برای همان اپراتور Score صفر می‌گیرد.
- **Confidence:** از Wilson lower bound و ترکیب نمونه‌های بلندمدت/اخیر استفاده می‌شود؛ بنابراین ۱۰۰ موفقیت از ۱۰۰ تست از ۲ موفقیت از ۲ تست معتبرتر است.
- **Performance:** فقط حداکثر ۶۰۰ رویداد ۴۸ ساعت اخیر همان Route/Operator خوانده می‌شود.
- **Concurrency:** ردیف Aggregate هنگام Update با `FOR UPDATE` قفل می‌شود تا Lost Update کاهش یابد.

## بدون Migration

این ارتقا ستون جدیدی به دیتابیس اضافه نمی‌کند و با جدول‌های فعلی سازگار است. وضعیت Block به‌صورت پویا از رویدادهای اخیر محاسبه و در Score همان Aggregate اعمال می‌شود.
