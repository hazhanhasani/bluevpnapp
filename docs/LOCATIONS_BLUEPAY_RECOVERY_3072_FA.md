# BlueVPN 3.0.72 — بازیابی مکان‌ها و پرداخت BluePay

این نسخه دو خطای عملی نسخه 3.0.71 را برطرف می‌کند:

1. صفحه مکان‌ها دیگر در حلقه «در حال آماده‌سازی مکان‌ها» باقی نمی‌ماند. سرورها علاوه بر `subscriptionId` با GUID واقعی فهرست متعلق به اشتراک تطبیق داده می‌شوند. اگر واردکردن Subscription حساب Premium هنوز تمام نشده باشد، برنامه یک‌بار همگام‌سازی اجباری انجام می‌دهد و تا ۱۴ ثانیه منتظر انتشار سرورها در MMKV می‌ماند.
2. ساخت فاکتور BluePay در Android به‌جای مهلت ۱۲ ثانیه، مهلت ۵۰ ثانیه دارد؛ چون Backend خودش برای دریافت فاکتور از Provider زمان نیاز دارد. Backend نیز کل عملیات Provider را به ۳۸ ثانیه محدود می‌کند و همیشه خطای JSON قابل‌نمایش برمی‌گرداند.

## سازگاری BluePay

- لینک‌هایی مانند `/developers/{merchant}/{api-key}` خودکار به API Root تبدیل می‌شوند.
- کلید قرارگرفته در لینک developers در صورت خالی‌بودن فیلد API Key استخراج می‌شود.
- هدرهای `X-API-Key`، `Api-Key` و `Authorization: Bearer` پشتیبانی می‌شوند.
- پاسخ‌های موفق دارای `Location` بدون بدنه JSON نیز قابل پردازش هستند.
- خطای غیرمنتظره Provider دیگر به‌صورت صفحه HTML/خطای مبهم به اپلیکیشن ارسال نمی‌شود.
