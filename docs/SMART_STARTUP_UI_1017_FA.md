# BlueVPN 1.0.17 — رابط ورود و بهینه‌سازی شروع

- Android: 1.0.17
- Version Code: 31
- Build ID: 20260804133922

## ورود و ثبت‌نام

- هدر گرافیکی و لوگوی BlueVPN
- توضیح کوتاه قابلیت‌ها
- فیلدهای حرفه‌ای ایمیل و رمز
- دکمه اصلی ورود و دکمه جداگانه ساخت حساب
- نمایش پیام‌های خطا و وضعیت در همان صفحه
- حفظ سیستم Refresh Token و ورود پایدار نسخه‌های قبل

## همگام‌سازی هنگام ورود به برنامه

- در هر ساخت Activity اصلی، پنجره بهینه‌سازی نمایش داده می‌شود.
- درصد از ۰ تا ۱۰۰ نمایش داده می‌شود.
- حساب و لینک اشتراک همگام می‌شوند.
- فهرست کانفیگ‌ها دوباره بارگذاری می‌شود.
- تمام سرورها با اینترنت همان کاربر Real Ping می‌شوند.
- بهترین مسیر سالم از قبل انتخاب می‌شود.

## مدیریت سرورهای ناموفق

- مسیر دارای نتیجه منفی فقط برای همان نوبت اجرای برنامه از صف سریع حذف می‌شود.
- در ورود بعدی، همه علامت‌های موقت پاک و همان مسیرها دوباره آزمایش می‌شوند.
- اگر هیچ مسیر سالمی باقی نماند، مسیرهای کنارگذاشته‌شده به‌عنوان fallback حفظ می‌شوند.
- بخش لوکیشن‌ها تعداد فعال و موقتاً کنارگذاشته‌شده را نشان می‌دهد.

## تشخیص لوکیشن

- ابتدا پرچم، کشور و شهر داخل Remark بررسی می‌شود.
- بعد کد کشور، TLD و توکن‌های امن hostname بررسی می‌شوند.
- نام‌هایی مانند Server، Node، Config و نام ارائه‌دهنده هرگز عنوان لوکیشن نمی‌شوند.
- مسیر نامشخص با `🌐 لوکیشن ناشناخته` نمایش داده می‌شود.
