# نصب بسته کامل BlueVPN 0.4.0

این ZIP را بدون استخراج برای ربات دائمی BlueVPN ارسال کنید.

ربات:
1. فایل‌های پروژه را با GitHub ادغام می‌کند.
2. فایل‌های دیگر مخزن را پاک نمی‌کند.
3. Dockerfile و فایل‌های کلید امضا را از طریق ZIP جایگزین نمی‌کند.
4. Commit و Push می‌زند.
5. GitHub Actions ساخت APK امضاشده را آغاز می‌کند.
6. خروجی APK را در تلگرام ارسال می‌کند.

## نکته Dockerfile

اگر هنوز Dockerfile دائمی ربات را یک بار به‌صورت دستی در GitHub نگذاشته‌اید،
ابتدا فایل `Dockerfile` داخل همین ZIP را مستقیماً در GitHub جایگزین کنید.
پس از آن، تمام آپدیت‌های بعدی را فقط برای ربات ارسال کنید.

## PostgreSQL در Railway

در سرویس اصلی BlueVPN این Variable را بسازید:

```env
DATABASE_URL=${{ Postgres.DATABASE_PRIVATE_URL }}
```

نیازی به ساخت دستی جدول نیست؛ برنامه جدول موردنیاز را خودکار ایجاد می‌کند.
