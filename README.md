# BlueVPN 3.0.25 — ورود با شماره تماس و فراز اس‌ام‌اس

این نسخه ورود و ثبت‌نام ایمیل/رمز را با ورود بدون رمز از طریق شماره موبایل ایران و کد یک‌بارمصرف جایگزین می‌کند.

## امکانات اصلی

- ورود و ثبت‌نام خودکار با شماره تماس و OTP
- ارسال سریع کد با پترن Faraz SMS / IPPanel Edge
- تنظیم کامل API Key، سرشماره و پترن از پنل مدیریت؛ بدون متغیر Railway
- حفظ حساب‌ها، اشتراک‌ها و نشست‌های قدیمی
- اتصال شماره تماس به حساب‌های ایمیلی قبلی
- کد رمزنگاری‌شده، زمان‌دار، یک‌بارمصرف و متصل به دستگاه
- محدودیت تلاش، ارسال مجدد و نرخ درخواست
- Migration خودکار دیتابیس به Schema 12
