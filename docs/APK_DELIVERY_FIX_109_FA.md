# اصلاح ارسال APK — BlueVPN 1.0.9

## علت سردرگمی قبلی

بسته پروژه نسخه 1.0.8 بود اما نسخه Android روی 1.0.2 قرار گرفته بود؛ بنابراین
APK جدید با نام 1.0.2 ارسال می‌شد و شبیه فایل قدیمی به نظر می‌رسید.

همچنین منطق نام‌گذاری Workflow روی بعضی خروجی‌های Gradle یک پسوند اضافه
می‌کرد و نام فایل به شکل `.apk.apk` درمی‌آمد.

## اصلاح

- نسخه Android: 1.0.9
- Version Code: 23
- Build ID: 20260804101620
- پسوند خروجی دقیقاً یک‌بار `.apk` خواهد بود.

- پیام شامل نسخه، شماره Build و Commit است.
- دو APK معماری arm64-v8a و armeabi-v7a ارسال می‌شوند.
- تغییرات همگام‌سازی یک‌دقیقه‌ای و انتخاب سراسری سرور نسخه قبلی حفظ شده‌اند.
