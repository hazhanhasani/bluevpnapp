# BlueVPN 1.0.21 — کنترل واقعی اپلیکیشن

## تنظیمات پنل

- تعمیرات: اتصال و استفاده را واقعاً مسدود می‌کند.
- آپدیت اجباری: تا نصب نسخه جدید اجازه اتصال نمی‌دهد.
- دانلود خودکار: APK مناسب معماری گوشی را دانلود می‌کند.
- اطلاعیه: برای هر شناسه فقط یک بار نمایش داده می‌شود.
- حداقل نسخه: نسخه‌های پایین‌تر را مجبور به بروزرسانی می‌کند.
- لینک پشتیبانی در پیام تعمیرات قابل استفاده است.

Android اجازه نصب کاملاً بی‌صدا به اپ معمولی نمی‌دهد. BlueVPN دانلود را
خودکار انجام می‌دهد و صفحه رسمی نصب Android را خودکار باز می‌کند؛ کاربر فقط
تأیید امنیتی نهایی سیستم‌عامل را می‌زند.

## اتصال

- دکمه اتصال هنگام بررسی دیگر قفل نیست و به «لغو اتصال» تبدیل می‌شود.
- توقف دستی تمام Callbackهای Failover را باطل می‌کند.
- دستور توقف Xray چند بار با فاصله کوتاه تکرار می‌شود تا Race رفع شود.
- Callback قدیمی دیگر بعد از قطع دستی، اتصال را دوباره روشن نمی‌کند.

## همگام‌سازی و سرعت رابط

- Ticker یک‌دقیقه‌ای حذف شد.
- بازگشت از تنظیمات، اشتراک یا لوکیشن شبکه را دوباره Sync نمی‌کند.
- همگام‌سازی فقط در اجرای تازه Activity اصلی انجام می‌شود.
- بازشدن بخش‌ها بدون Transition سنگین و با قفل ضد دوبار کلیک انجام می‌شود.
- آمار زنده اتصال همچنان هر ثانیه فقط از حافظه محلی بروزرسانی می‌شود.
