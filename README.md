# BlueVPN 3.0.43

این نسخه پنل مدیریت BlueVPN را به‌صورت Mobile-First بازطراحی می‌کند. تمام بخش‌های مدیریت، فرم‌ها، جدول‌ها، تبلیغات، کاربران و پرداخت‌ها روی نمایشگر گوشی بدون فعال‌کردن حالت دسکتاپ قابل استفاده‌اند.

برای ساخت APK و انتشار Backend، ZIP را در ربات Build یا مخزن GitHub بارگذاری کنید.
