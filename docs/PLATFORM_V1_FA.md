# BlueVPN Platform 1.0.0

## قابلیت‌ها

- ثبت‌نام و ورود با ایمیل و رمز عبور
- نشست امن با توکن هش‌شده
- محدودیت ۱ یا ۲ دستگاه بر اساس پلن
- تعریف چند پنل PasarGuard در پنل مدیریت
- اتصال PasarGuard با API Key یا نام کاربری/رمز مدیر
- تعریف پلن با قیمت، مدت، حجم، گروه‌ها و تعداد دستگاه
- ساخت فاکتور BluePay و استعلام وضعیت پرداخت
- دریافت Callback امضاشده BluePay و جلوگیری از پردازش تکراری
- ساخت یا تمدید خودکار کاربر در PasarGuard
- تحویل لینک Subscription اختصاصی به اپ
- همگام‌سازی در ورود، بازگشت به برنامه و پس از پرداخت
- تشخیص نسخه جدید و نمایش دانلود APK

## متغیرهای Railway

```env
ADMIN_USERNAME=admin
ADMIN_PASSWORD=رمز_قوی
SESSION_SECRET=عبارت_تصادفی_طولانی
DATA_ENCRYPTION_KEY=عبارت_تصادفی_جداگانه
PUBLIC_BASE_URL=https://bluevpnapp-production.up.railway.app
DATABASE_URL=${{ Postgres.DATABASE_PRIVATE_URL }}
```

متغیرهای ربات و GitHub قبلی را حذف نکنید.

## راه‌اندازی پنل PasarGuard

از مسیر «پاسارگارد» در پنل مدیریت:

1. نام و Base URL را وارد کنید.
2. روش احراز هویت را انتخاب کنید.
3. در حالت API Key، کلیدی با دسترسی خواندن/ساخت/ویرایش کاربران وارد کنید.
4. در حالت مدیر، نام کاربری و رمز مدیر را وارد کنید.
5. Proxy Settings JSON پیش‌فرض کاربر جدید را وارد کنید.
6. دکمه تست را بزنید.

مسیرهای مورد استفاده:

- `GET /api/users`
- `GET /api/user/by-username/{username}`
- `POST /api/user`
- `PUT /api/user/by-username/{username}`

## راه‌اندازی BluePay

در ربات احرازشده BluePay برای فروشگاه API Key و Callback Secret بسازید. سپس در بخش BluePay وارد کنید.

Callback URL:

```text
https://bluevpnapp-production.up.railway.app/webhooks/bluepay
```

Backend از مسیرهای زیر استفاده می‌کند:

- `POST /api/v1/invoices`
- `GET /api/v1/invoices/{payment_id}`

## تمدید

اگر کاربر قبلاً در PasarGuard وجود داشته باشد، تاریخ جدید از بزرگ‌ترِ «اکنون» و «تاریخ انقضای فعلی» محاسبه می‌شود. سپس همان کاربر و همان Subscription تمدید می‌شوند.

## دستگاه‌ها

Backend ورود دستگاه‌ها را کنترل می‌کند و مقدار `hwid_limit` را نیز هنگام ساخت یا تمدید کاربر در PasarGuard روی ۱ یا ۲ قرار می‌دهد. مدیر می‌تواند از بخش کاربران همه نشست‌ها و دستگاه‌های حساب را بازنشانی کند.

## آپدیت APK

در بخش «اپ و آپدیت» این موارد را تنظیم کنید:

- نسخه و Version Code
- لینک مستقیم APK
- توضیحات نسخه
- اجباری یا اختیاری بودن

اپ هنگام بازشدن، تنظیمات نسخه را بررسی می‌کند و در صورت وجود نسخه جدید لینک دانلود و نصب را نمایش می‌دهد. Android اجازه نصب کاملاً بی‌صدا را به اپ عادی نمی‌دهد و تأیید نهایی نصب با کاربر است.
