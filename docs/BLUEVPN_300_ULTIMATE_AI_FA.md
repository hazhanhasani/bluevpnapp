# BlueVPN 3.0 Ultimate AI

Build ID: `20260805135429`

## معماری

Android → BlueVPN Backend → PostgreSQL AI events/aggregates → پیشنهادهای اپراتورمحور

## داده‌های جمع‌آوری‌شده

فقط اپراتور، نوع شبکه، شناسه هش‌شده مسیر، کشور، پینگ، مدت اتصال، نتیجه اتصال و نسخه برنامه. محتوای ترافیک، آدرس سایت‌ها و پیام‌ها ذخیره نمی‌شوند.

## منطق امتیاز

ترکیب پایداری، مدت اتصال، پینگ، Jitter/Packet Loss، حجم نمونه، تجربه شخصی و تجربه کاربران مشابه.

## حالت ایمن

اگر BlueAI یا Backend در دسترس نباشد، الگوریتم پینگ و Failover قبلی بدون وابستگی به AI ادامه می‌دهد.
