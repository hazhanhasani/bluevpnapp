# BlueVPN 1.0.8

- Android: 1.0.2
- Version Code: 22
- Build ID: 20260804100440

## اشتراک

- اطلاعات حجم و اعتبار از حساب فعلی Backend نمایش داده می‌شود.
- کش اطلاعات اشتراک قدیمی بعد از Sync و خروج پاک می‌شود.
- حساب، URL اشتراک و فهرست سرورها هر ۶۰ ثانیه خودکار به‌روز می‌شوند.
- Sync هنگام شروع و بازگشت به برنامه هم اجرا می‌شود.
- کنترل‌های بروزرسانی دستی از خانه، حساب و تنظیمات حذف شدند.

## انتخاب خودکار سرور

- «لودبالانس هوشمند» به «انتخاب خودکار سرور» تغییر کرد.
- این گزینه به بالای صفحه لوکیشن‌ها منتقل شد.
- در حالت خودکار تمام سرورها در تمام لوکیشن‌ها بررسی می‌شوند.
- دکمه صفحه لوکیشن‌ها تست واقعی همه سرورها را اجرا می‌کند.
- انتخاب یک کشور، حالت خودکار را خاموش و همان کشور را دستی انتخاب می‌کند.
- اتصال نهایی با بررسی واقعی اینترنت داخل Xray تأیید می‌شود.
